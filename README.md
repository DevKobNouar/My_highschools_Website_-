# 🏫 High School Static Website Project  

**🚀 Modern Static Website** for my high school featuring:  
- **🌐 Fully Responsive Design** (works on all devices)  
- **🧭 Interactive Navbar** with smooth scrolling  
- **📚 Organized Sidebar** for quick navigation  
- **✨ Clean Body Sections** with engaging content  
- **👋 Welcoming Introduction** section  
- **🗺️ Comprehensive User Guide** explaining all site elements  

**🛠️ Built With:** HTML5, CSS3, Tailwind, JavaScript,.
**🎯 Goal:** Create an intuitive digital hub for students and staff!
